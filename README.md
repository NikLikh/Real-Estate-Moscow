# Real Estate in Russia

**Цель проекта**:
Проект посвящён прикладному анализу рынка недвижимости в Москве и Московской области с целью выявления наиболее оптимальных объектов и временных интервалов для инвестирования в нежвижимость. В рамках проекта будет проведён анализ цен на недвижимость, выявление трендов и закономерностей, а также разработка рекомендаций для инвесторов.

**Задачи проекта**:
1. Сбор и подготовка данных о недвижимости в Москве и Московской области.
2. Анализ цен на недвижимость в зависимости от различных факторов (расположение, тип недвижимости, площадь, количество комнат и т.д.).
3. Выявление трендов и закономерностей на рынке недвижимости.
4. Разработка рекомендаций для инвесторов по выбору объектов недвижимости и оптимальных временных интервалов для инвестирования.

**Инструменты**:
1. DA: Python (Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn)
2. Scrapping: Playwright, KaggleHub, BeautifulSoup, Selenium, Scrapy
3. DE: PostgreSQL, Apache Airflow, Docker, onETL, Spark

**Подготовка данных**:
1. Сбор данных из различных источников, включая открытые данные, сайты недвижимости и специализированные платформы через дата-пайплайн.
2. Нормализация данных, включая стандартизацию формата, удаление лишних символов и приведение данных к единому виду.
3. Очистка данных от пропусков, аномалий и дубликатов.
4. Преобразование данных в удобный формат для анализа (в частности, необходимо получить данные о временных изменениях цен на недвижимость).
